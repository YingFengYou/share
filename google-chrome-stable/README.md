# Google Chrome Stable for Linux (amd64)

本目录对应 Google 官方提供的 Google Chrome Stable AMD64 Debian 安装包。

由于该 `.deb` 文件大小超过 GitHub 普通 Git 仓库的单文件限制，安装包作为 GitHub Release 资产发布，而不是直接提交到 Git 历史中。

- 官方下载地址：https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
- 软件包：`google-chrome-stable`
- 版本：`151.0.7922.169-1`
- 架构：`amd64`
- 下载入口：[Chrome Stable Release](https://github.com/YingFengYou/share/releases/tag/google-chrome-stable-151.0.7922.169)
- 安装包资产：`google-chrome-stable_current_amd64.deb`

下载后可使用仓库中的 `SHA256SUMS` 文件验证完整性。
